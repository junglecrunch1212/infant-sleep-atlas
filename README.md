# Infant Sleep Atlas

An evidence audit and playbook for infant sleep from 4 to 12 months: what moves long-term outcomes, what doesn't, and where the real risk is. 43 popular claims graded against the primary literature, with sources.

Static site, no build step: `index.html`, `styles.css`, `atlas.js`. Served by GitHub Pages from `main`.

Evidence through October 2026. Figures marked "Modelled" are calculations, not measurements.
